# 💰 Ledger Book — Expense Tracker

A responsive personal expense tracker built with **HTML, CSS, and JavaScript**.  
It helps users record income and expenses, manage transactions, and visualize their spending.

## ✨ Features

- 💵 Track income and expenses in Indian Rupees (₹)
- 📊 View total income, total expenses, and current balance
- 🏷️ Categorize transactions
- 📅 Add transaction dates
- ✏️ Edit existing transactions
- 🗑️ Delete transactions
- 📈 View spending by category
- 📊 Monthly spending chart
- 🌙 Dark/Light theme toggle
- 📥 Export transactions as CSV
- 🧹 Clear all transactions
- 💾 Data is stored locally in the browser
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- HTML Canvas

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Start adding your income and expenses.

No installation or external dependencies are required.
